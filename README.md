# 🎨 Pipette

> Генератор цветовых палитр на основе фотографий

**Android • Kotlin • Jetpack Compose**

---

## О приложении

Pipette — мобильное приложение для Android, которое мгновенно извлекает доминирующие цвета из любой фотографии и представляет их в виде удобной палитры с HEX-кодами. Достаточно навести камеру или выбрать снимок из галереи — и палитра готова.

---

## Кому подойдёт

**🖌️ Дизайнерам и художникам**
Мгновенно получайте цветовые схемы из реального мира: интерьеров, природы, рекламных макетов, арт-объектов. Копируйте HEX-коды прямо в дизайн-инструменты (Figma, Adobe, Procreate) без ручного подбора.

**📷 Фотографам**
Анализируйте цветовое решение кадра прямо на съёмочной площадке. Pipette помогает выстраивать единый визуальный стиль серии снимков и контролировать цветовую температуру.

**💻 Разработчикам**
Быстро извлекайте цвета из брендбуков, UI-скетчей или скриншотов приложений и сразу переносите их в код в виде готовых HEX-констант.

**👗 Стилистам и специалистам по визуальному мерчандайзингу**
Подбирайте гармоничные сочетания цветов одежды, аксессуаров и предметов интерьера прямо на месте, опираясь на точные цветовые данные.

**📣 Маркетологам и контент-мейкерам**
Выстраивайте визуальную идентичность бренда, извлекая палитры из референсов, упаковки или локаций.

## Функциональность

### 📷 Экран камеры
- Встроенная камера с **пипеткой**: крестик в центре считывает цвет пикселя в реальном времени и показывает HEX-код
- **Pinch-to-zoom** — приближение и отдаление жестом; сохранённое фото соответствует зуму на экране
- Выбор количества цветов в палитре: **3, 6, 9, 12 или 15**
- Нажатие на плашку цвета пипетки или иконку копирования — HEX в буфере обмена
- Быстрый переход в галерею и раздел «Избранное»

### 🎨 Экран результата
- Отображение обработанного фото и сгенерированной палитры
- При **3 цветах** — расширенный вид с крупными плашками и HEX-кодом
- При **6–15 цветах** — компактный вид для удобного просмотра всей палитры
- Нажатие на плашку — копирование HEX в буфер обмена
- Кнопка-сердце: добавление цвета в избранное (иконка становится красной), повторное нажатие — удаление

### ❤️ Экран «Избранное»
- Список сохранённых цветов с HEX-кодами, хранится локально
- Нажатие на плашку — копирование HEX
- Иконка корзины — удаление цвета
- Добавление нового цвета вручную по HEX-коду
- Защита от дублей: один и тот же цвет нельзя добавить дважды

## Запрашиваемые разрешения

| Разрешение | Назначение |
|---|---|
| `CAMERA` | Съёмка через встроенную камеру |
| `READ_MEDIA_IMAGES` | Выбор фото из галереи (Android 13+) |
| `READ_EXTERNAL_STORAGE` | Выбор фото из галереи (Android 8–12) |

> Галерея открывается через системный пикер — приложение получает только URI выбранного файла, без доступа ко всему хранилищу.

## Как запустить

### Требования
- Android **8.0 (API 26)** и выше
- Устройство с камерой
- Android Studio **Hedgehog (2023.1.1)** или новее
- JDK 17

### 1. Клонировать репозиторий
```bash
git clone https://github.com/your-username/Pipette.git
cd Pipette
```

### 2. Открыть в Android Studio
`File → Open` → выбрать папку проекта. Дождаться завершения Gradle Sync.

### 3. Подключить устройство
1. Включите **режим разработчика**: Настройки → О телефоне → нажать «Номер сборки» 7 раз
2. Включите **Отладку по USB**: Настройки → Для разработчиков → Отладка по USB
3. Подключите телефон кабелем и разрешите отладку во всплывающем окне

### 4. Собрать и запустить
Нажмите **▶ Run** (`Shift+F10`) или через терминал:
```bash
./gradlew installDebug
```

### Получить APK
```bash
./gradlew assembleDebug
```
Файл будет по пути:
```
app/build/outputs/apk/debug/Pipette-v1.0.apk
```
